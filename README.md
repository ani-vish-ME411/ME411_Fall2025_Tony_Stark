There are 2 main motors: Servo and Stepper (DC). The codes have been divided in the following way:


Servo Codes: 
            /n Arduino_Play_Sound_Servo_Movement.py 
            /n Main_Sound_411.mp3 
            /n Project_Main_Servo_Arduino_Code.ino

1. Open the python script and add the file location of the appropriate audio file.
2. Make sure you open and run the python code before you start any of the interactions or else the auido from the speakers won't play
3. Make sure the python script is running in the background so you don't have to keep running the script to hear the audio.
